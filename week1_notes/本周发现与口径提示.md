# 第1周 · 本周发现与口径提示

> 附在指标拆解练习之后，作为「先排除假下跌 / 样本偏差」的真实案例。

## 1. 数据底数（建库导入后自检）
- 总行数：100,000
- 行为分布：pv=89709 / cart=5446 / fav=2744 / buy=2101
- 时间范围：2017-09-11 ～ 2017-12-03（真正密集活跃段 11-25 ～ 12-03）

## 3. 浏览→购买整体转化率（用户口径）
- 来过的人（pv 去重）：980
- 买过的人（buy 去重）：671
- 转化率 = 671 / 980 = **68.47%**

## 4. ⚠️ 必须说清的口径坑（面试加分项）
这 10 万行是**按 user_id 升序取的前 10 万行**，因此只覆盖**最早的约 980 名用户**。
这 980 人是高频活跃用户（人均出现约 100 次），他们的购买转化率天然偏高。
所以 68.47% **不能**被解读为「全站转化率」，只是这部分样本的特征。

**这恰好印证了指标拆解练习第 0 步**：拿到一个「指标下跌 / 异常」结论前，
先问三件事——数据口径对不对？样本是不是有偏？时间周期对齐没？
第8周面试追问 1「你这个转化率下降，有没有可能是数据口径或时间周期导致的」
用这个真实案例就能答得很扎实。
